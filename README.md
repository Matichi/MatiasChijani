## 🚀 Sobre mí

Soy un desarrollador con foco en construir productos digitales funcionales, mantenibles y con buena experiencia de usuario. Me interesa trabajar en proyectos donde pueda combinar lógica, diseño, datos y automatización para resolver problemas reales.

Actualmente estoy fortaleciendo mi perfil en:

- Desarrollo de aplicaciones web modernas.
- Integración de APIs y servicios externos.
- Automatización de procesos y flujos de trabajo.
- Diseño de interfaces limpias, responsivas y fáciles de usar.
- Buenas prácticas de versionado, documentación y mejora continua.

> Este perfil está pensado como una base inicial. Cuando tenga mi CV actualizado, iré agregando más experiencia, logros, certificaciones y proyectos destacados.
