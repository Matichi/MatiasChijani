## Sobre mí

Soy profesional de datos con experiencia en **Business Intelligence, Data Science, automatización, ETL, web scraping y desarrollo de dashboards**. He trabajado liderando proyectos BI, migraciones entre plataformas analíticas, automatización de reportes y construcción de soluciones de datos para clientes.

Mi base técnica viene de la **ingeniería, astronomía y astrofísica**, donde usé Python para simulación, análisis de datos, investigación y colaboraciones científicas. Hoy combino ese enfoque analítico con herramientas modernas de BI, cloud, automatización e inteligencia artificial aplicada a productos de datos.

- Santiago, Chile
- Experiencia en consultoría BI, analítica avanzada y automatización
- Interés en soluciones que mezclan datos, IA, visualización y producto
- Idiomas: español nativo, inglés profesional, japonés intermedio

## En qué trabajo

- **Dashboards y BI:** diseño, desarrollo y mejora de tableros en Qlik Sense, Power BI y AWS QuickSight.
- **ETL y automatización:** procesos automatizados en Python para extracción, limpieza, transformación y carga de datos.
- **Data Science:** análisis exploratorio, modelamiento, machine learning y visualización con el ecosistema Python.
- **Web scraping:** extracción de datos con Selenium, Scrapy y BeautifulSoup para monitoreo y análisis.
- **Cloud y datos:** trabajo con servicios en AWS, Azure, Redshift, SQL y MySQL.
- **IA aplicada:** integración de herramientas como ChatGPT, DeepSeek y modelos LLM en flujos de analítica y dashboards.

## Proyectos y líneas de trabajo

### BI y analítica empresarial

Construcción de dashboards ejecutivos y operacionales, definición de indicadores, modelamiento de datos y migraciones entre Qlik Sense, Power BI y servicios cloud. El foco está en convertir datos dispersos en información clara para decisión.

### Automatización de datos con Python

Desarrollo de scripts y procesos ETL para automatizar reportes, consolidar fuentes, validar información y reducir trabajo manual. Uso frecuente de Pandas, SQL, APIs, scraping y procesamiento batch.

### IA aplicada a dashboards

Integración de asistentes, modelos LLM y herramientas de IA en flujos de analítica para acelerar exploración de datos, generar explicaciones y apoyar la toma de decisiones.

### Investigación, simulación y ciencia de datos

Experiencia académica en astronomía y astrofísica, con trabajo en simulación, análisis de observaciones, Python científico y colaboraciones publicadas en Astronomy & Astrophysics.
